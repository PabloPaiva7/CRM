# 📋 CRM Simples - Gestão de Clientes

Este é um sistema simples de **CRM (Customer Relationship Management)** desenvolvido com **Streamlit**. Ele permite gerenciar clientes, incluindo **cadastro**, **atualização**, **remoção** e **listagem de informações**.

---

## 🚀 Funcionalidades

### 📄 Listar Clientes
- Exibe todos os clientes cadastrados
- Mostra informações como:
  - ID
  - Nome
  - E-mail
  - Telefone
  - Status (Ativo/Inativo)

### ➕ Adicionar Cliente
- Permite cadastrar novos clientes com:
  - Nome completo
  - E-mail
  - Telefone
  - Status (Ativo/Inativo)
- Gera automaticamente um **ID único** para cada cliente

### ✏️ Atualizar Cliente
- Permite atualizar as informações de um cliente existente:
  - Nome
  - E-mail
  - Telefone
  - Status (Ativo/Inativo)

### ❌ Remover Cliente
- Permite remover um cliente do sistema
- Exibe uma **confirmação** antes da exclusão

---

## 🛠️ Tecnologias Utilizadas
- **Python**
- **Streamlit** – Para a interface do usuário
- **Pandas** – Para manipulação de dados
- **OS** – Para manipulação de arquivos
